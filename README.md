# Sam Lupton - Personal Website

Built with React and deployed on GitHub Pages.

## 🚀 Live Demo

Visit the live website: [https://sam-lupton.github.io](https://sam-lupton.github.io)

## 🛠️ Tech Stack

- **Frontend**: React 18
- **Styling**: CSS3 with custom animations
- **Fonts**: Orbitron, Share Tech Mono
- **Deployment**: GitHub Pages
- **Contact Form**: Formspree
- **Build Tool**: Create React App

## 📦 Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/sam-lupton/sam-lupton.github.io.git
cd sam-lupton.github.io
```

2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## 🚀 Deployment

The website is automatically deployed to GitHub Pages when changes are pushed to the main branch.

To manually deploy:

```bash
npm run build
npm run deploy
```

## 🎨 Customization

### Colors

The vaporwave color scheme uses:

- Primary: `#ff00ff` (Hot Pink)
- Secondary: `#00ffff` (Cyan)
- Accent: `#00ff00` (Lime Green)
- Background: Dark gradients with `#0a0a0a` base

### Fonts

- Headers: Orbitron (futuristic, bold)
- Body: Share Tech Mono (monospace, retro)

### Animations

- Gradient shifts
- Neon glow effects
- Floating elements
- Smooth transitions

## 📱 Sections

- **Hero**: Animated introduction with typing effect
- **About**: Personal information and skills showcase
- **Projects**: Portfolio with filtering capabilities
- **Contact**: Contact form and social links

## 🔧 Available Scripts

- `npm start` - Runs the app in development mode
- `npm run build` - Builds the app for production
- `npm run deploy` - Deploys to GitHub Pages
- `npm test` - Launches the test runner
- `npm run eject` - Ejects from Create React App
